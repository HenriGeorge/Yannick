# Hooks reference

Last updated: 2026-10-19 08:40

Per-hook detail: what each script enforces, at which event, its bypass, and real gotchas. The
gate policy, bypass-token roster and PR-merge axes live in `ENFORCEMENT.md` — this file is the
per-hook detail it links to.

## How hooks are wired

Hooks ship canonically in the `ct-hooks-py` plugin (`plugins/ct-hooks-py/hooks/*.py`), wired via
that plugin's `hooks/hooks.json` (generated by `bin/build-hook-wiring.sh` from
`hook-wiring/registry/*.json` — never hand-edit the generated files; `merge_settings_hooks.py` is
a setup-time utility, not a runtime hook). `_dispatch.py` is the shared entry loop a consolidated
hook's modules run through. The dispatcher CLI form used elsewhere in this workflow is
`claude-template gate-run` — see `hook-wiring/README.md` for the rules-vs-hooks boundary (when a
check becomes a hook vs. stays a rule).

A launcher pointed at a missing hook file exits 0 (skip, never a block) — a retired-but-still-wired
entry degrades silently, with a stderr breadcrumb and a stdout `systemMessage`.

## Event map

| Event | Hook(s) |
|---|---|
| SessionStart | `session_start`, `figma_launch` (async), `cloud_session` (startup\|resume), `session_autoff`, `rules_refresh` |
| PreToolUse (Bash\|PowerShell\|Agent\|Task\|Write\|Edit\|NotebookEdit\|Read) | `pre_tool` (runs the guard battery) |
| PreToolUse (Bash) | `rtk_rewrite` (rtk's command-rewrite, as a plugin hook — docs/RTK.md) |
| PreToolUse (Bash\|PowerShell) | `pr_gate` |
| PostToolUse (Write\|Edit) | `post_tool_use_lint` |
| PostToolUse (all) | `telemetry` |
| PreCompact | `session_crumb` |
| Stop | `stop_record` |
| WorktreeCreate | `worktree_create` |
| WorktreeRemove | `worktree_remove` |
| TeammateIdle | `teammate_idle` |
| SessionEnd (clear\|other) | `session_crumb` |

## Hook entries

### `session_start` — inject GATE-0 baseline + HANDOFF into context
- **Event:** SessionStart · **Trigger:** every start/resume · **Effect:** inject (never blocks)
- **Bypass:** none
- Computes the behind/ahead count vs the default remote branch and surfaces the primary
  worktree's `HANDOFF.md`. Fails silently (no crash) outside a git repo, detached HEAD, no
  `origin`, or any git/read error.

### `figma_launch` — opt-in Figma environment launcher
- **Event:** SessionStart (async) · **Trigger:** `source == "startup"`, macOS/Linux, and an
  uncommented `FIGMA_LAUNCH=1` in `.claude/worktrees.conf` · **Effect:** provision (open Figma,
  spawn the bridge) — never blocks startup
- **Bypass:** omit/comment out `FIGMA_LAUNCH=1`
- The bundled ClaudeTalkToFigma bridge hardcodes `Bun.serve({port: 3055})` with no hostname, so it
  binds `0.0.0.0` — **LAN-reachable and unauthenticated**, with no upstream flag/env to restrict
  the interface. Firewall `:3055` or stay on a trusted network; see the `figma-bridge` skill.

### `cloud_session` — cloud-only environment bring-up
- **Event:** SessionStart (startup\|resume) · **Trigger:** `CLAUDE_CODE_REMOTE=true` · **Effect:**
  provision (docker, dependency re-sync, `supabase start`, env files, seed) — fail-open
- **Bypass:** none (no-op outside a cloud session)
- Re-syncs only when the lockfile hash changed since `.claude/state/cloud-setup.stamp`; notes carry
  key/step names only, never values.

### `session_autoff` — auto-fast-forward + sideways staleness warning
- **Event:** SessionStart · **Trigger:** every start · **Effect:** DIRECT auto-ff of *this* repo's
  primary checkout when behind+clean+on-trunk+ff-able; sideways WARN-only for a stale
  plugin-source primary · **Effect:** provision/WARN — fail-open
- **Bypass:** none; never touches a non-trunk branch
- Never auto-ffs a repo you didn't open — the sideways leg only reads and warns.

### `rules_refresh` — sync always-core rules from the plugin
- **Event:** SessionStart · **Trigger:** `source == "startup"` · **Effect:** provision (byte-sync
  `.claude/rules/*.md` from the plugin, commit if the tree is clean)
- **Bypass:** none; a dirty tree (any staged/unstaged tracked change) skips with a warning
- Fail-open and silent on any error.

### `pre_tool` — the guard battery (single PreToolUse entry)
- **Event:** PreToolUse (Bash\|PowerShell\|Agent\|Task\|Write\|Edit\|NotebookEdit\|Read) ·
  **Trigger:** every matching tool call · **Effect:** BLOCK (deny) or WARN, joining every triggered
  guard's reason into one deny
- **Bypass:** per-guard, see the table below
- Reads stdin once, builds one context, and runs every guard below in a fixed order (commit-only
  guards run only when `"commit" in command`, for speed). `--only <guard>` reproduces one retired
  hook's old output byte-for-byte for legacy wiring.

| Guard | Blocks / warns | Bypass |
|---|---|---|
| `conventional_commit` | non-conventional `git commit -m` subject grammar | none (fix the message; only `-m` subjects are inspected) |
| `danger` | `rm -rf` on sensitive paths, force-push to main/master, `reset --hard` to a remote ref, clobbering another agent's worktree | `CT_ALLOW_DANGER=1` (segment-scoped) |
| `db_ops` | destructive SQL (`DROP TABLE`/`DROP DATABASE`/`TRUNCATE`/`ALTER TABLE`/`DROP INDEX`) outside a dry-run | none |
| `env_write` | shell redirect (`>`/`>>`/`cat >`) overwriting `.env` | none |
| `giant_file` | staging a file over `CT_MAX_FILE_MB` (default 10) | `CT_ALLOW_BIGFILE=1` (segment-scoped), or raise `CT_MAX_FILE_MB` |
| `grill` | committing a spec/plan/ADR with no non-empty `## Grill findings` | `WORKFLOW:no-grill` |
| `model` | an Agent/Task `model` param that isn't an exact pinned ID (bare alias, `[1m]` suffix, `opusplan`, `default`) | none — pass the exact ID |
| `nocommit_guard` | staged diff ADDS a merge-conflict marker, a leftover-artifact sentinel comment, or `.DS_Store` | `WORKFLOW:no-nocommit` |
| `parallel` | a plan with ≥2 tasks missing `## Parallelization`, or same-batch tasks touching the same file | `WORKFLOW:no-parallel` |
| `plan_interview` | committing a plan with no non-empty `## Questions resolved` — WARN only since #1427 (a `systemMessage` note, never a deny) | `WORKFLOW:no-interview` |
| `plugin_cache` | in-place Edit/Write to the machine-global plugin cache (`~/.claude/plugins/{cache,marketplaces}`) | `CT_ALLOW_PLUGIN_EDIT=1` |
| `protected_branch` | direct `git commit`/`git push` on main/master | `CT_ALLOW_PROTECTED=1` (segment-scoped) |
| `readonly` | `rm -rf` or Write/Edit inside a configured read-only path | none |
| `reminders` | inject-only: PR-review nudge on `gh pr merge`, docs-staleness, worktree-prune note | n/a (never blocks) |
| `secret_file` | staging an obviously-secret filename (`.env*` deny-list minus `.env.example`/`.env.sample`/`.env.test`) | `CT_ALLOW_SECRET_FILE=1` (segment-scoped) |
| `secret_read` | reading an obviously-secret file (SSH keys, etc.) via Read or a shell dumper | `CT_ALLOW_SECRET_READ=1` |
| `secret_scan` | staged diff contains an AWS key / private-key header / generic token assignment | `CT_ALLOW_SECRETS=1` (segment-scoped) |
| `session_prime` | first mutation (Edit/Write/NotebookEdit or commit) on a **managed** repo before the session is worktree-isolated AND primed; a docs-only target, or an index-only `commit -m` over a docs-only staged set, is exempt (#1427) | `WORKFLOW:no-worktree` / `WORKFLOW:no-prime` / `PRIME_GATE=0` |
| `shared_checkout` | a mutating git op in a primary checkout another live session shares | `CT_ALLOW_SHARED=1` (segment-scoped) — prefer your own worktree |
| `stale_base` | `git commit` behind `origin/main` whose staged files overlap files that changed upstream since the merge-base | `WORKFLOW:no-rebase-check` (honored only mid-`git merge origin/main`) |
| `tdd` | see paragraph below | `WORKFLOW:no-tdd` |
| `template_owned` | in-place Edit/Write to a pristine template-owned file (still byte-identical to its recorded install hash) | fork the file first, or `CT_ALLOW_TEMPLATE_EDIT=1` (vendor_owned path) |
| `test_lock` | running the test runner / the project's `TEST_CMD` outside `bin/test-lock` | `CT_ALLOW_UNLOCKED_TESTS=1` |
| `vendor_owned` | editing a `.claude/<kind>/<rest>` copy that mirrors a `plugins/<plugin>/<kind>/<rest>` source | `CT_ALLOW_TEMPLATE_EDIT=1` |
| `worktree_cwd` | `git add`/`commit` whose cwd silently fell back to the primary checkout from a vanished worktree | none (fix the cwd) |

**`tdd` in detail.** Fires on `git commit`; classifies every staged file as TEST / SOURCE /
NEUTRAL and BLOCKs when the staged set has ≥1 SOURCE change and 0 TEST changes. What it verifies:
a test file changed *alongside* a source change in the same commit. What it does **not** verify: it
never runs a test, never confirms a test was observed failing (RED), and never checks the test is
meaningful — a commit pairing any source edit with any test-glob-matching file passes. Classification
is conservative (unknown extensions default NEUTRAL, never SOURCE) and extendable per-project via
`TDD_GATE_TEST_GLOBS` / `TDD_GATE_SOURCE_GLOBS`. Fails open on `--amend`, a merge commit, no staged
files, not-a-repo, or any git error — this is V1 commit-time enforcement only. Roadmap: V2
test-meaningfully-changed-before-impl (diff the test body, not just its path) → V3
test-actually-failed (capture a real RED run before the GREEN commit) → V4 an adversarial agent
validates the test against the implementation before it lands.

### `rtk_rewrite` — rtk's command-rewrite, as a plugin hook (docs/RTK.md)
- **Event:** PreToolUse (Bash) · **Trigger:** every Bash call · **Effect:** ALLOW, never blocks
  (fail-open)
- No bypass needed — it's never a gate. No-ops (exit 0, no output) for a non-Bash tool, `rtk`
  absent from PATH, a `git`/`/usr/bin/git` command (excluded so a worktree-isolated `git` is never
  rewritten into an `rtk git` form the worktree-isolation guard refuses, #709), or a command
  already prefixed `rtk `. Otherwise relays the SAME stdin JSON to `rtk hook claude` and forwards
  its stdout verbatim, but ALWAYS exits 0 itself (never propagates rtk's own exit code — this hook
  rewrites, it never gates). Replaced rtk's own machine-global `rtk init -g` hook (#1410/#1411/
  #1412 — a global `~/.claude/settings.json` hook can't work in a claude.ai cloud session, which
  has no persistent machine-global config).
- **Cloud:** reaches a fleet repo only after `CLOUD_VENDOR=1` in `.claude/worktrees.conf` + `propagate.sh --apply` (the guarded `.claude/hooks/rtk_rewrite.py` entry is written by `bin/sync-hooks-wiring.sh` on that path alone).

### `pr_gate` — `gh pr create`/`gh pr merge` gate
- **Event:** PreToolUse (Bash\|PowerShell) · **Trigger:** a `gh pr …` subcommand · **Effect:**
  BLOCK
- **Bypass:** `WORKFLOW:no-design` (create without a spec/plan added on the branch) /
  `WORKFLOW:force-merge` (merge without green/mergeable CI)
- `gh pr create` on a `feat/*` branch with no spec/plan added on the branch (diffed against the
  merge-base with trunk, not a repo-wide file search) → BLOCK. `gh pr merge` whose CI isn't green
  or whose PR isn't cleanly mergeable → BLOCK. Fails OPEN whenever `gh` is
  offline/unauthenticated/unparseable. Also emits a non-blocking WARN nudge to dispatch a reviewer
  on every successful create. See `ENFORCEMENT.md` for the merge-axes markers it also checks.

### `post_tool_use_lint` — auto-lint after Write/Edit
- **Event:** PostToolUse (Write\|Edit) · **Trigger:** a Python file write/edit · **Effect:** inject
  (runs the formatter/linter, never blocks)
- **Bypass:** none
- Fails open on unparseable stdin.

### `telemetry` — metadata-only tool-call recorder
- **Event:** PostToolUse (all tools) · **Trigger:** every tool call · **Effect:** inject (append to
  `.claude/telemetry/tool-events.jsonl`)
- **Bypass:** `CLAUDE_TELEMETRY=0` / a `TELEMETRY=` false value in `worktrees.conf`
- Metadata only — no bodies/prompts/diffs captured. Always exits 0.

### `session_crumb` — re-grounding crumb before context loss
- **Event:** PreCompact, SessionEnd(clear\|other) · **Trigger:** every compact/clear/end ·
  **Effect:** inject (writes branch/staged/last-test/open-questions to a crumb file)
- **Bypass:** none
- Guarded only by cwd — fail-open, silent on any error, never breaks a `/clear` or `/compact`.

### `stop_record` — Stop-time session-summary logger
- **Event:** Stop · **Trigger:** every stop · **Effect:** inject (append a row to
  `.claude/session-logs/<date>.jsonl`, 30-day retention)
- **Bypass:** none
- Never blocks the stop; fails open on malformed stdin.

### `worktree_create` — provision a native worktree
- **Event:** WorktreeCreate · **Trigger:** a new worktree request (payload carries only `name`) ·
  **Effect:** provision — creates the worktree, echoes its absolute path on stdout (the harness
  switches the session into it)
- **Bypass:** none
- Also: `git fetch origin` in the primary checkout (warn-only offline), a GATE-0 behind-origin
  WARN, gitignored `.env*` copy-in, and a collision-free `PORT` reservation. All diagnostics go to
  stderr so stdout stays a single path line.

### `worktree_remove` — back up before teardown
- **Event:** WorktreeRemove · **Trigger:** a worktree removal · **Effect:** provision (backs up
  untracked/ignored files + an uncommitted-changes patch to
  `~/.local/share/claude-template/backups/<repo>/<wt>-<ts>/`, frees the worktree's PORT)
- **Bypass:** none
- Log-only event (cannot block); always exits 0.

### `teammate_idle` — keep a crew teammate working
- **Event:** TeammateIdle · **Trigger:** a teammate goes idle · **Effect:** BLOCK the idle (exit 2
  with a nudge) while `pending_tasks` is non-empty; otherwise allow
- **Bypass:** none (clear its pending tasks)
- Fail-open (exit 0) on malformed input.

## Shared modules

- `_dispatch` — the shared entry loop a consolidated hook's modules run through; joins their
  `systemMessage`s into one.
- `_ff_checkout` — the safe fast-forward primitive `session_autoff` calls.
- `_git` — shared git-runner with a hard-deadline clamp; fails open (returns `None`) but leaves a
  stderr breadcrumb, so a *blind* allow is distinguishable from a *clean* one.
- `_telemetry_gate` — shared opt-out resolution (`CLAUDE_TELEMETRY` / `worktrees.conf TELEMETRY=`)
  for the telemetry writers; missing module degrades to enabled.
- `pre_tool_use` — legacy sentinel: runs only `pre_tool.py`'s old pre-consolidation checks, for a
  repo still wired to this hook name.
