# Grill me (interview)

Run a `/grilling` session — relentless, one round of questions at a time, a recommended
answer attached to each, until shared understanding is reached. This is the human-in-the-loop
interview; it grills the person. For the autonomous adversarial review used as a GATE-1
pressure-test, use `grill-me` (devil's-advocate review the model runs itself).
